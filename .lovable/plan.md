

# Opium Trade Essay — Visual & Animation Enrichment

## What's there now
The "Ledger Noir" color scheme, typography, and section structure are excellent. But every section is text + static tables/small SVGs. No imagery, no animated data visualizations, no atmospheric textures, no visual moments that make you stop scrolling.

## What's needed
Rich visual storytelling layered into the existing structure: animated flow diagrams, historical imagery, atmospheric effects (tea stains, ink bleeds), and bespoke data-art moments per section.

## Plan

I'll create a design philosophy document and a visual canvas artifact that defines the imagery/animation language for this essay — then in the next step, implement it in code.

### Step 1: Design Philosophy (.md)
**"Mercantile Corrosion"** — a philosophy about precision degrading into stain, accounting surfaces hiding violence, commodity flows as living organisms on paper.

### Step 2: Canvas (.pdf)
A single-page visual artifact expressing the philosophy — the trade triangle as a living diagram on aged ledger paper, with tea-amber and resin-brown staining, ruled lines, and commodity glyphs. This becomes the reference board for all visual additions to the essay.

### What gets built after (implementation phase)
Per-section visual additions:
1. **Hero**: Animated silver coins flowing along the triangle watermark; the triangle pulses with commodity colors
2. **Silver Drain**: Animated "bullion thermometer" — a vertical bar filling with silver, then draining; coin-stack counters
3. **Commutation Act**: Animated bar chart showing tax rate collapse and demand surge; tea-cup consumption counter
4. **Factories**: Cross-section blueprint diagram of the 5-step factory process with scroll-triggered progression; resin stain bleeding into margins
5. **Routes**: Maritime chart-style SVG map with animated ship routes along the three legs; monsoon wind arrows; Lintin Island glow
6. **Reversal**: The signature moment — animated balance scale tipping, silver flow arrows reversing direction, color shift from amber to resin
7. **Lin Zexu**: Animated chest counter (20,283 counting down); destruction pit cross-section; Victoria letter as a document facsimile with wax seal
8. **Treaty**: Contract document styling with stamped/sealed terms; coast map showing five treaty ports
9. **Epilogue**: Final stats with animated counters; the ledger "closes" — a page-turn or binding effect

### Atmospheric layer (global)
- Faint ruled-line animation (shimmer on scroll)
- Tea-stain CSS gradients that intensify per section variant
- Ink-blot SVG accents at section transitions
- Paper grain texture overlay
- EIC monogram watermark (very faint, rotating per section)
